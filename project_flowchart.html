2. Google Login & Role Selection Logic

The specific flow for handling new vs. existing users via Google Auth.

sequenceDiagram actor User participant FE as Frontend participant BE as Backend participant DB as Database User->>FE: Sign in with Google FE->>BE: Send Google Token BE->>BE: Verify Token alt New User BE->>DB: Check Email (Not Found) BE->>DB: Associate 'VISITOR' Role BE-->>FE: Return Token + Role 'VISITOR' FE->>User: Redirect to Role Selection Page User->>FE: Select Role (Buyer/Seller) FE->>BE: Update Role Request BE->>DB: Save New Role FE->>User: Redirect Home else Existing User BE->>DB: Check Email (Found) BE-->>FE: Return Token + Existing Role FE->>User: Redirect Home end
